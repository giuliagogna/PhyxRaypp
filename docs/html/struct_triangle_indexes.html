Detailed Description

Index triplet describing a triangular face in an indexed mesh.

Stores the indices of the three vertices composing a triangle, along with the corresponding normal and texture-coordinate indices as defined by the .obj format.

All indices refer to elements stored in the Mesh vertex, normal, and UV arrays.
