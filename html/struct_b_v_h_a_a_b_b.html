Detailed Description

Axis-Aligned Bounding Box for spatial partitioning.

Used to encapsulate geometry. If a ray misses the AABB, it guarantees the ray misses all geometry contained within it, allowing for fast early rejection during BVH traversal.

◆ intersect()

bool BVHAABB::intersect ( const Ray & ray) const
inline

Tests whether a ray intersects the bounding box.

Uses the slab intersection algorithm, computing the entry and exit intervals along each coordinate axis and combining them into a single valid intersection range.

The implementation employs precomputed inverse ray directions and sign checks to minimize branching during traversal.

Parameters
rayRay to test.
Returns
True if the ray intersects the box within the interval [ray.tmin, ray.tmax], false otherwise.
