Detailed Description

Affine transformation storing both a matrix and its inverse. It stores the direct matrix of the transformation and its inverse: when applying transformation to a Point or Vec one should use the direct matrix. One often wants to apply the inverse transformation: to do so we implement a method inverse() that simply switches the two matrixes, so that now the inverse is the direct and vice-versa.
