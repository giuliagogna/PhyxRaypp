Detailed Description

Parsed command-line parameters used to configure program execution.

This structure stores all options extracted from the CLI, including input/output files, rendering settings, image dimensions, and path-tracing configuration parameters.

Members are initialized with the same default values used when the corresponding command-line option is omitted.
