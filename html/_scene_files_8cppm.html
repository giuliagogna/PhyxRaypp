◆ parse_scene()

std::expected< Scene, GrammarError > parse_scene ( InputStream & input_file,
const std::unordered_map< std::string, float > & overridden_variables = {} )
export

Parses an entire scene file from top to bottom, building the World, Camera, and Materials.

This function acts as the root of the recursive descent parser. It sequentially reads top-level tokens (Float variables, Materials, Cameras, and Shapes) and populates a Scene object.

Parameters
input_fileThe InputStream pointing to the .txt scene file.
overridden_variablesAn optional dictionary of float variables injected from the command line.
Returns
A fully populated Scene object, or a GrammarError if a syntax violation occurs.

template<typename T>
std::expected< std::unique_ptr< Shape >, GrammarError > parse_shape ( InputStream & input_file,
Scene & scene )
export

Parses a specific shape geometry and its applied material from the input stream.

Reads the transformation matrix and material identifier for a shape. Performs a dictionary lookup to bind the shape to an already-defined material in the scene.

Template Parameters
TThe specific Shape class to instantiate (e.g., Sphere, Plane, Cube).
Parameters
input_fileThe input stream currently pointing to the shape's parameter list.
sceneThe active Scene object containing the material dictionary.
Returns
A unique pointer to the newly allocated Shape.
Warning
Throws a GrammarError if the material name is not found in the scene's dictionary. Transformation is an optional argument
