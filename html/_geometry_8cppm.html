Detailed Description

Core geometric primitives, vector algebra, and spatial transformations.

This module defines points, vectors, normals, homogeneous matrices, and affine transformations used throughout the renderer.

The distinction between Point, Vec, and Normal is intentional and helps prevent invalid geometric operations at compile time.

template<typename VectorType>
std::array< Vec, 3 > create_onb_from_z ( const VectorType & normal)
export

Build an orthonormal basis from a normalized direction.

The input vector becomes the local z-axis of the generated basis.

Template Parameters
VectorTypeVec or Normal.
Parameters
normalNormalized direction.
Returns
Array containing {e1, e2, e3}. Create a orthonormal basis (ONB) from a vector representing the z axis (normalized) Return a tuple containing the three vectors (e1, e2, e3) of the basis. The result is such that e3 = normal. The normal vector must be normalized, otherwise this method won't work.
